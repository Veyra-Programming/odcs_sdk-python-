**ODCS Python SDK** is a Python development toolkit for exploring offline-first computing, digital continuity and resilient software architectures.

Developed under **Veyra-Programming**, this SDK is part of the broader **Open Digital Continuity Standard (ODCS)** ecosystem.

> Connectivity should enhance technology, not control it.

## 🚀 About ODCS

The Open Digital Continuity Standard explores an approach to software development in which applications can preserve important operations, manage local information and support synchronization when connectivity becomes unavailable or unreliable.

The ODCS Python SDK aims to make ODCS-related development concepts accessible to Python developers.

## ✨ Project Goals

- **Offline-first computing:** Encourage applications that can operate without continuous internet connectivity.
- **Digital continuity:** Explore ways to preserve application operations and state.
- **Local data management:** Support continuity-oriented local data workflows.
- **Synchronization:** Explore mechanisms for coordinating information across systems.
- **Resilient architecture:** Help developers build applications that handle connectivity interruptions.
- **Python integration:** Provide a Python interface for ODCS-related development.

*These are project goals and intended areas of development, not a claim that every capability is currently implemented.*

The planned PyPI distribution name is `odcs-core`.

